## 一、目标

将现有"紫色渐变 + 多彩气泡 + 重阴影"的活泼风格，重构为 **克制、理性、内心平静** 的极简冷调设计。核心理念：**用空间和呼吸感说话，通过黑白灰的明暗对比建立层级，不依赖色彩吸引注意力。**

---

## 二、色彩体系

全局不引入彩色——层级完全通过黑白灰的明暗对比建立。

| 角色 | 色值 | 用途 |
|---|---|---|
| 页面底色 | `#F2F2F7` | 全局背景（iOS 系统级浅灰） |
| 内容底色 | `#FFFFFF` | 内容区纯白 |
| 侧边栏底色 | `#F8F8F8` | 比内容区微深一阶 |
| 主文字 | `#1D1D1F` | 标题、正文 |
| 辅助文字 | `#6E6E73` | 标签、说明文字 |
| 弱文字 | `#AEAEB2` | 占位符、禁用态、时间戳 |
| 分割线 | `#E5E5EA` | 极细分隔 |
| 强调色 | `#2C2C2C` | 按钮、选中态、交互元素、实心指示点 |

## 三、布局与间距

- **无卡片容器**：所有页面去掉 Ant Design `<Card>` 包裹。内容直接以区块排列，区块间用 `32px` 留白分隔，必要时加一条 `border-bottom: 1px solid #E5E5EA`
- **全局内边距**：内容区 `padding: 40px`（移动端 `24px`）
- **最大宽度**：保持 `max-width: 1200px`，居中布局，两侧自然留白
- **组件间距**：列表项、表单项间距从 `8-12px` 放大到 `16-20px`

## 五、字体与排版

- **字体族**：保持系统默认 `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, ...`
- **标题**：`24px / weight 600 / #1D1D1F / letter-spacing: -0.3px`
- **区块标题**：`17px / weight 500 / #1D1D1F`
- **正文**：`15px / weight 400 / #1D1D1F / line-height: 1.6`
- **辅助文字**：`13px / #6E6E73`
- **数据数字**：`font-variant-numeric: tabular-nums`，确保数字对齐

## 六、组件重设计

### 状态指示器（替代 BubbleTag）

去掉彩色渐变气泡，改为纯文字 + 小圆点：

```
• 已认养    ◦ 待认养    • 已绝育    ◦ 未绝育
```

- 实心圆点 `•` → `color: #2C2C2C`，表示肯定状态
- 空心圆 `◦` → `color: #AEAEB2`，表示否定/非活跃状态
- 字号 `13px`，颜色 `#6E6E73`，点与文字间距 `6px`

### 性别标识（替代 GenderBadge）

去掉彩色圆形底色，改为纯文字 + 符号：
- `♂ 公` / `♀ 母` / `? 未知`
- 字号 `13px`，颜色 `#6E6E73`

### 统计数据

大数字：`40px / weight 500 / #1D1D1F / letter-spacing: -1px`
下方标签：`13px / #AEAEB2 / text-transform: uppercase`

### 按钮

- 主按钮：背景 `#2C2C2C`，文字 `#FFFFFF`，`border-radius: 8px`，无阴影
- 次按钮：背景透明，边框 `1px solid #D1D1D6`，文字 `#1D1D1F`
- 危险按钮：文字 `#FF3B30`，边框 `1px solid #FF3B30`，背景透明
- hover 态：主按钮变 `#1D1D1F`，次按钮背景 `#F2F2F7`

### 表格

- 表头：背景 `#F8F8F8`，文字 `#6E6E73 / weight 500 / 12px / uppercase`
- 行分割：`border-bottom: 1px solid #F2F2F7`
- 行 hover：背景 `#FAFAFA`
- 去掉斑马纹、深色表头

### 表单

- 输入框：`border: 1px solid #D1D1D6`，`border-radius: 8px`，focus 时边框变为 `#2C2C2C`
- Label：`13px / weight 500 / #1D1D1F`，与输入框间距 `8px`

### 空状态

- 文字 `14px / #AEAEB2`，居中对齐，上下留白充足（`padding: 64px 0`）
